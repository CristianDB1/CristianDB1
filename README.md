## 👨‍💻 Sobre mí

Soy desarrollador de software de **Carepa, Antioquia (Urabá)**. Me dedico a convertir problemas reales de negocios pequeños y de la región en **productos web que funcionan**: desde plataformas SaaS multi-empresa hasta catálogos que reciben pedidos por WhatsApp.

- 🏗️ Diseño y construyo el producto completo: base de datos, API, interfaz y despliegue.
- 🌍 Me interesa la tecnología aplicada a mi región: **logística portuaria, comercio local y pymes**.
- 🧪 Cuido la calidad: pruebas automatizadas, tipado estricto y despliegue continuo.
- 📚 Aprendo construyendo: cada proyecto me deja una herramienta nueva.
